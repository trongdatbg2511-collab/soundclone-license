🔑 Cấp key SoundClone

—

Tạo tại github.com/settings/tokens → Fine-grained token → chọn đúng repo này → quyền Contents: Read and write. Đừng cấp quyền rộng hơn mức đó.

Token chỉ nằm trong trình duyệt điện thoại này, không gửi đi đâu ngoài GitHub. Mất điện thoại thì vào github.com/settings/tokens huỷ token đó là xong.

Thêm vào màn hình chính: Safari bấm Chia sẻ → Thêm vào MH chính, Chrome bấm ⋮ → Thêm vào màn hình chính.
